Mission 3.3

Migration serveur Active Directory

Accueil Missions Mission 3

🚨 Contexte de la mission

Ce projet consiste à migrer l'infrastructure Active Directory de l'entreprise d'un serveur Windows Server 2012 (obsolète) vers Windows Server 2025. L'objectif est de sécuriser l'annuaire et d'optimiser la gestion des utilisateurs sur plusieurs sites distants.

En raison de l'écart de versions, nous avons opté pour une reconstruction saine et manuelle de l'arborescence (OU et comptes) afin de nettoyer les données historiques.
