Mission 3

Gestion de serveur

Accueil Missions

🖥️ Description de la mission

Contexte :
L'administration de serveurs est une mission essentielle chez LOGIN Informatique. J'interviens sur la mise en place, la configuration et la maintenance des serveurs de nos clients, qu'ils soient physiques ou virtualisés.

Objectifs :
• Installer et configurer des serveurs Windows et Linux
• Gérer les services réseau (DNS, DHCP, Active Directory)
• Mettre en place des solutions de virtualisation
• Assurer la sécurité et la sauvegarde des données
• Superviser et maintenir les serveurs en production

Outils utilisés :
• Systèmes : Windows Server 2019/2022, Debian, Ubuntu Server
• Virtualisation : VMware ESXi, Hyper-V, VirtualBox
• Services : Active Directory, DNS, DHCP, serveur de fichiers
• Sauvegarde : Veeam Backup, scripts de sauvegarde
• Supervision : PRTG, Zabbix

📋 Tâches réalisées

Installation de serveurs :
Installation de Windows Server 2019/2022 et de distributions Linux (Debian, Ubuntu Server), configuration initiale du système, mise en place de la sécurité de base, installation des mises à jour.

Configuration de services réseau :
Déploiement et configuration d'Active Directory (création de domaine, gestion des utilisateurs et groupes), mise en place de serveur DNS pour la résolution de noms, configuration de serveur DHCP pour l'attribution d'adresses IP.

Virtualisation :
Installation et configuration d'hyperviseurs (VMware ESXi, Hyper-V), création et gestion de machines virtuelles, allocation des ressources (CPU, RAM, stockage), migration de serveurs physiques vers des environnements virtualisés.

Sécurité et sauvegarde :
Configuration de pare-feu Windows et iptables sous Linux, mise en place de stratégies de sauvegarde automatiques, tests de restauration, durcissement de la sécurité des serveurs (désactivation de services inutiles, mise à jour, etc.).

Maintenance et supervision :
Surveillance des performances serveur, gestion des logs et événements système, application des correctifs de sécurité, optimisation des performances, documentation des configurations.

💡 Compétences mobilisées

Administration Windows Server :
• Installation et configuration de Windows Server
• Active Directory (AD DS, GPO, utilisateurs, groupes)
• Services réseau (DNS, DHCP, WSUS)
• Serveur de fichiers et gestion des partages
• PowerShell pour l'automatisation

Administration Linux :
• Installation de distributions serveur (Debian, Ubuntu)
• Ligne de commande et scripts Bash
• Gestion des utilisateurs et permissions
• Configuration de services (Apache, SSH, FTP)
• Sécurisation avec iptables

Virtualisation :
• Hyperviseurs Type 1 (ESXi) et Type 2 (VirtualBox)
• Création et gestion de VMs
• Allocation et optimisation des ressources
• Snapshots et clonage
• Migration et consolidation de serveurs

Sécurité et sauvegarde :
• Stratégies de sauvegarde (complète, incrémentale, différentielle)
• Plan de reprise d'activité (PRA)
• Sécurisation des accès serveur
• Gestion des mises à jour de sécurité

🎯 Résultats obtenus

Ces missions d'administration serveur m'ont permis de développer une expertise complète en gestion d'infrastructures IT. J'ai pu mettre en œuvre des solutions de virtualisation qui ont permis à nos clients d'optimiser leurs ressources et de réduire leurs coûts.

La mise en place de stratégies de sauvegarde robustes garantit la continuité d'activité en cas d'incident. Les solutions de supervision déployées permettent une détection rapide des problèmes et une intervention proactive.

Cette expérience a renforcé ma capacité à gérer des environnements serveur complexes, aussi bien sous Windows que sous Linux, et m'a préparé efficacement à mon futur métier d'administrateur systèmes et réseaux.
